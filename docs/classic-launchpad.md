# 经典启动台 1.0.6

为习惯 macOS 15 及以前 Launchpad 的用户制作的独立原生替代程序。采用全屏图标网格、模糊壁纸、搜索、分页和文件夹，尽量接近旧版体验；并非苹果原版，布局细节与系统私有动画无法保证完全相同。

## 安装与程序坞打开

从旧版更新：先按 Command-Q 退出旧版，再把新版拖入“应用程序”并替换原程序。沿用原来的排序和文件夹，不需要清空布局。首次从 1.0 升级时，会把仍散放在主界面的内建工具归入“其他”；你已经手动整理的文件夹会保留。1.0.3 新增排序与排序撤销文件，应用会在需要时自动创建；它不替代原布局备份。

1. 打开 DMG，将“经典启动台.app”拖到“应用程序”；或解压 ZIP 后将程序拖入“应用程序”。
2. 在“应用程序”中双击“经典启动台”。
3. 按 Esc 收起界面，在程序坞中右键它的图标，选择“选项 → 在程序坞中保留”。也可以直接将应用程序中的图标拖入程序坞。
4. 以后点击程序坞图标即可打开；收起后程序仍在后台，Command-Q 才会完全退出。

当前提供 Apple Silicon 版本，适用于 M 系列 Mac。已在本机 macOS 27.0 上运行验证；最低构建目标为 macOS 13，其他系统版本尚未实测。Intel Mac 不适用此安装包。

程序使用本地 ad-hoc 签名，已验证签名完整性，尚未经过 Apple 开发者证书签名和公证。下载、复制到其他电脑后，系统可能要求确认开发者；签名完整性验证不等同于 Gatekeeper 公证通过。本程序不要求关闭系统安全保护。

## 使用方法

- 单击应用图标：打开应用。小幅鼠标抖动仍视为点击；移动达到 10 个屏幕点后才进入重排拖拽。
- 点击搜索框输入中文或英文：搜索应用；按回车打开第一个结果。
- 滚动鼠标或触控板、点击底部圆点：切换页面。
- 在主区域图标之间的空白处按住鼠标左键，向左拖动到下一页、向右拖动回上一页。页面跟随鼠标，松手后吸附；短距离拖动会回弹，首末页不会循环。
- 滚轮、鼠标拖动、触控板切页：使用同一种翻页动画。动画过程中暂不响应新的滚轮切页，连续滚动时稍停片刻，避免页面互相追赶。
- 空白处右键（或按 ⌘,）→ 翻页手感：选择“经典（接近旧版）”“柔和”或“快速”，默认经典，重开后保留。系统“减弱动态效果”当前开启时，应用仍按选择播放翻页动画；如需关闭动画，可在本应用菜单中打开“跟随系统‘减弱动态效果’”。这不会更改系统设置。
- 空白处右键（或按 ⌘,）→ 排序全部页面：名称、添加时间、创建时间或修改时间，均可正序或倒序。时间来自应用文件夹元数据；文件夹按所含应用的最新时间参与排序，文件夹中的项目保留原顺序。应用文件的添加时间不可读取时，会采用创建时间。
- 文件夹展开后，排序菜单改为“排序当前文件夹”，只排列其中的应用，不移动文件夹位置。
- “撤销上次排序”恢复排序前的位置与分页。排序以后再手动整理，旧的撤销操作就会停用。
- 拖到另一图标中央：建立文件夹，或加入已有文件夹。
- 拖到图标名称或两侧：调整顺序。
- 拖到屏幕左右边缘停留：跨页移动；最后一页右侧可创建新页。此边缘交互尚未完成自动化 GUI 验证。
- 点击文件夹打开；点击名称修改，按回车保存。也可以右键选择重命名或解散。
- 文件夹内拖到面板外，或右键选择“移出文件夹”：回到主界面。
- Esc：依次返回文件夹外、清空搜索或收起启动台。
- 页面铺满 35 个图标时：单击最下一排图标下方的空白收起，包括程序坞两侧；主网格内普通空白点击保持显示。
- 页面未铺满时：单击任意实际空白处收起，包括未占用的格子、图标之间、下方以及程序坞两侧。图标、搜索框和实际分页圆点仍处理各自操作。
- 左右拖动继续翻页；短拖、反向拖回和底部拖动不会误关窗口。
- 文件夹展开时：点击面板外普通空白只返回主网格；程序坞两侧底部点击带仍直接收起整个启动台。
- 空白处右键或按 Command-逗号（⌘,）：打开选项菜单，可重新扫描、调整翻页手感、排序、查看说明或退出。图标上右键仍打开该图标的操作菜单。

首次启动自动查找 `/Applications`、`/System/Applications`、`~/Applications` 中的应用；包内辅助程序和后台程序不列入。自定义位置的应用可先移入上述应用程序文件夹，再重新扫描。新应用默认追加到末页。

默认按旧版方式设置“其他”文件夹，归拢终端、控制台、磁盘工具、脚本编辑器等系统工具，以及文本编辑、字体册等次要内建应用。备忘录、地图、播客、计算器等常用应用保留在外面。参考 [Apple 旧版“Mac 附带的应用”说明](https://support.apple.com/zh-cn/guide/mac-help/mchl110b00b7/10.13/mac/10.13)。

分组只在首次使用或升级时整理一次。你之后手动移出、解散或重命名“其他”，不会被重新扫描强制还原。新发现的应用仍按原规则追加到末页。

## 1.0.6 对齐原版截图

以用户提供的 6016×3384 像素旧版 Launchpad 截图为外观基准，收窄 7×5 网格，校准图标中心、行距、13 点文字及分页圆点；优先读取第三方应用包原始图标，避免新系统额外玻璃处理；去掉额外图标投影，减轻文字阴影，文件夹预览与应用可见尺寸对齐。搜索框为 250×26 点，空提示居中，输入、中文输入法及清除继续使用 AppKit 原生搜索控件。

主界面不再放右上角齿轮，选项改为空白处右键或 ⌘,。顶部仅在启动台活动时用窄背景覆盖菜单区域，保留真实 Dock；失焦、隐藏及退出时移除，不改系统菜单栏或 Dock 偏好。

第三方应用优先读取应用包的原始图标，资源缺失时使用系统图标；苹果应用继续由系统正确合成轮廓。因此不同 macOS 或应用版本的图标样式仍可能与截图不同。尚未同步其他应用的未读通知角标；不把未实现的角标显示宣称为已完成。翻页动画、布局存储、排序与 1.0.5 的内存释放机制沿用。

## 1.0.5 内存优化

壁纸采用最大 1600 像素的模糊纹理直接交给系统图层合成，遮罩及文件夹面板也改用图层，避免为每层分配整屏 Retina 绘图缓存。应用图标缓存只保留网格所需分辨率。收起后释放页面、图标和壁纸资源，下次打开自动恢复；显示时仍预热相邻页，保持现有高刷新率翻页机制。

本机相同布局、6016×3384 像素显示环境，以 `vmmap -summary` 的 physical footprint 比较：浏览三页后约 230 → 106 MB，收起后约 230 → 31 MB；连续开关 10 次后约 37 MB。数值随显示器、应用数量、系统缓存和测量时机变化，详见验证报告。

## 布局与恢复

布局只保存在本程序目录：`~/Library/Application Support/ClassicLaunchpad/layout.json`。
翻页手感及“跟随系统减弱动态效果”选项保存在同目录的 `preferences.json`；不会改变布局格式，缺失的选项会使用默认值。
每次布局更新保留上一版有效文件 `layout.json.backup`。最近一次排序的撤销快照另存为 `sort-undo.json`。遇到无法解析的布局会停止启动并提示，避免静默覆盖排序。恢复时请先退出程序并备份现有文件，再用 `.backup` 副本替换 `layout.json`。

本程序不修改旧 Launchpad 数据库或系统文件，不导入旧布局，不接管 F4、系统捏合手势，也不提供卸载其他应用的功能。多显示器下会尝试在鼠标所在屏幕打开；多屏行为尚未实测。

测试使用隔离目录，交付包不包含本机应用列表、测试排序或个人布局。

## 源码构建

源码为 Swift / AppKit / CoreImage，零第三方运行依赖。需要 macOS、Python 3 和 Xcode Command Line Tools：

```sh
python3 build.py --test --output dist
```

输出 `dist/经典启动台.app`，包含 59 项模型、排序、撤销、手势判定、真实视图命中和偏好存储测试。测试需要可用的 macOS 图形会话。macOS 14 及更高版本使用当前窗口所在显示器的显示同步回调处理拖动；macOS 13 使用系统图层合成及鼠标事件。构建脚本针对部分 Command Line Tools 中重复的 SwiftBridging modulemap 使用临时 VFS overlay，仅影响当前编译，不改工具链文件。

测试可通过 `CLASSIC_LAUNCHPAD_SUPPORT_DIR` 环境变量指定独立布局目录。详细验证范围见随附验证报告。
